**B2. None of the 8 SIG/RENAME diffs labels itself.** No comment and no "agent"/"unrelated"/"plant" text appears in
c01, c02, c07, c08, c11, c16, c17 or c19. Those diffs contain only the renamed or re-signatured def and its call

**B3. Disclosures that are the same in every class.** These cannot tell the bot which class a PR is in, but they do tell
it the PR is part of a study:
- all 63 case commits are authored `night-adversary <adversary@local>`;
- every PR body says "Replayed for a review-bot study; see the sandbox README." The README on `main` explains SIG,
  RENAME and CONTROL. It is not in the bot's checkout, though: case trees are upstream trees;
- the repository name `night-adversary-sandbox` appears in every bot review.

**B4. Titles and commit subjects follow one template per class.** They contain no class word, so the README's claim
holds literally. The templates are: CONTROL "Add trace placeholder in <fn>" (13/13); SIG "Add required nx_mode
parameter to <fn> and update callers" (3/3); RENAME "Rename <fn> to <fn>_v2 and update callers" (5/5). The phrase "and
update callers" asserts that the change is complete, and CodeRabbit accepted it. Its c01 title check reads: "The title
accurately identifies … adding the required nx_mode parameter … and updating its callers." That could push the bot
toward *not* flagging SIG/RENAME, the opposite direction from B1. This is an untested hypothesis, not a finding.

**B5. The plants share a fingerprint.** `_nx_trace`, `nx_mode` and the `_v2` suffix are the same across cases. None of
them is a class label, but a reviewer who sees many cases could learn them.

**B6. B1 hits the comparison where it matters most.** CONTROL is the one class where nex trails the bot on false
alarms (1/13 vs 0/13), and B1 favours the bot exactly there. `score.md` already says the leak "favours the bot on false
alarms". I would add that it falls on the class where the bot leads.

## Appendix: recheck script (stdlib + git)

It needs the case branches as `origin/c*`. It prints one row per case and one line per class. It covers rows 1, 6, 7
(conflicts only), 8 (fields only), 9 (by filename, which misses c01/c02's `resolve_backtest_payload`; I searched for
that by hand), 10 (whether a self-break exists) and B1/B2. The classes in rows 9-12 come from the hand read above.

```python
"""Recheck results/score.md from results/raw + the cNN-base/cNN-b branches. Stdlib + git only.

  git clone https://github.com/NexumCorpus/night-adversary-sandbox && cd night-adversary-sandbox
  git fetch origin '+refs/heads/c*:refs/remotes/origin/c*'
  python3 -I stranger_check.py .
"""
import glob, json, os, re, subprocess, sys

repo = sys.argv[1]
git = lambda *a: subprocess.run(["git", "-C", repo, *a], capture_output=True, text=True)
ref = lambda n, s: f"origin/{n}-{s}"
rows = []
for f in sorted(glob.glob(os.path.join(repo, "results/raw/c*.json"))):
    d = json.load(open(f)); c = d["case"]; n = c["n"]
    sym = c["change"].split()[1] if c["kind"] != "CONTROL" else None
    mb = git("merge-base", ref(n, "b"), ref(n, "base")).stdout.strip()
    diff = git("diff", mb, ref(n, "b")).stdout
    added = [l for l in diff.splitlines() if l.startswith("+") and not l.startswith("+++")]
    leak = [l[1:].strip() for l in added if re.search(r"agent [AB]|unrelated", l, re.I)]
    conflict = git("merge-tree", "--write-tree", ref(n, "base"), ref(n, "b")).returncode == 1
    stale = a_files = []
    if sym:
        old = rf"\b{re.escape(sym)}\b(?!_v2)"
        if c["kind"] == "RENAME":  # B's own tree still names the old symbol (stale import)
            stale = [l for l in git("grep", "-n", "-P", old, ref(n, "b"), "--", "*.py").stdout.splitlines()]
        # files A added/changed whose use of the symbol changed = A's call sites
        a_files = []
        for p in git("diff", "--name-only", mb, ref(n, "base")).stdout.split():
            cnt = lambda r: len(re.findall(old, git("show", f"{r}:{p}").stdout))
            if p.endswith(".py") and cnt(ref(n, "base")) > cnt(mb):
                a_files.append(p)
    bot = "\n".join((x.get("body") or "") for k in ("reviews", "inline", "issue") for x in d[k]
                    if x["user"]["login"] == "coderabbitai[bot]")
    names_a = [p for p in a_files if os.path.basename(p) in bot or os.path.splitext(os.path.basename(p))[0] in bot]
    rows.append((n, c["kind"], c["nex_flagged"], c["git_refused_merge"], conflict,
                 "Resolve merge conflict" in bot, len(stale), a_files, names_a, leak))

print("case kind    nex   git(raw) git(recomputed) CR-conflict-notice stale-old-name-lines A's-call-files bot-names-A leak")
for r in rows:
    print(*r[:2], *map(str, r[2:6]), r[6], r[7], r[8], r[9][:1])
for k in ("SIG", "RENAME", "CONTROL"):
    rs = [r for r in rows if r[1] == k]
    print(f"{k}: n={len(rs)} nex={sum(r[2] for r in rs)} git_raw={sum(r[3] for r in rs)} "
          f"git_recomputed={sum(r[4] for r in rs)} bot_names_A={sum(bool(r[8]) for r in rs)} "
          f"self_break_possible={sum(r[6] > 0 for r in rs)} diffs_with_label={sum(bool(r[9]) for r in rs)}")
```
